# 10 ready WhatsApp Business quick replies

Copy-paste replies for shop owners: hello, price, hours, address, payment, delivery, stock, wait, confirm, thanks.

**Get the file:** [ready_replies.txt](https://github.com/pranjal-25-2006/replies/blob/main/ready_replies.txt) (or open it and tap Raw to copy).

**How to use**
1. Open WhatsApp Business > Settings > Business tools > Quick replies > Add
2. Type the shortcut (for example `/price`) and paste the message
3. Change the `[brackets]` to your own details
4. In any chat, type `/` and pick the reply

Also set a Greeting message for new customers and an Away message for when your shop is closed.
